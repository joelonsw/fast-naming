# 🎯 Fast-Naming Agent TODO - 1등 달성을 위한 개선 과제

## ⚠️ 현재 1등을 못할 수 있는 이유

### 1. 데이터 부족
- **문제**: Few-shot 예시가 제한적 (examples.json)
- **영향**: 수상작 패턴 학습 부족
- **개선**:
  - [ ] 역대 수상작 데이터 수집 자동화
  - [ ] 공모전 유형별 수상작 DB 구축 (최소 50개+)
  - [ ] 수상작 특징 분석 리포트 생성

### 2. 공모전별 맞춤화 부족
- **문제**: 모든 공모전에 동일한 전략 적용
- **영향**: 특정 주최기관의 선호도 반영 못함
- **개선**:
  - [ ] 주최기관별 성향 분석 (예: 삼성 vs 정부기관)
  - [ ] 공모전 분야별 특화 프롬프트 (관광, IT, 환경 등)
  - [ ] 지역 특색 반영 (울산=산업, 제주=관광 등)

### 3. 평가 기준의 한계
- **문제**: LLM 자체 평가는 실제 심사와 다를 수 있음
- **영향**: 높은 점수 ≠ 실제 수상
- **개선**:
  - [ ] 실제 수상작 vs 미수상작 비교 학습
  - [ ] 사람 평가 피드백 수집 시스템
  - [ ] A/B 테스트 기반 전략 최적화

### 4. Rate Limit으로 인한 생성 제한
- **문제**: LLM 호출 수 제한 → 다양성 부족
- **영향**: 최적의 후보를 놓칠 수 있음
- **개선**:
  - [ ] 비동기 배치 처리 최적화
  - [ ] 캐싱을 통한 중복 호출 제거
  - [ ] 여러 세션으로 분산 생성

### 5. 실시간 트렌드 반영 부족
- **문제**: 현재 트렌드/유행어 미반영
- **영향**: 세련되지 않은 구식 표현 생성
- **개선**:
  - [ ] 실시간 SNS 트렌드 키워드 수집
  - [ ] 최근 수상작 트렌드 분석
  - [ ] MZ세대 용어 사전 업데이트
